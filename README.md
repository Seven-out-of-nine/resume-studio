# 简历造物所 Resume Studio

一款本地优先、所见即所得的中文简历生成器。用户可以选择简历风格，把需要的内容模块拖入 A4 简历，填写个人信息后通过浏览器生成 PDF。

## 已实现功能

- 十八套简历模板：织绿、留白、铅字、夜航、侧影、燕麦、潮汐、墨刻、柑橘、鸢尾、瑞格、矩阵、典藏、樱笺、林间、霓虹、晨报、峰会
- 九类内容模块：个人简介、工作经历、教育经历、项目经历、专业技能、语言能力、证书资质、荣誉奖项、自定义模块
- 从模块库拖入简历、简历内拖拽排序，以及适合触屏的上移/下移按钮
- 所见即所得的表单编辑，支持多条经历增删、模块重命名、隐藏和删除
- 头像上传、主题色、字体气质和内容密度设置
- 浏览器本地自动保存，不上传个人信息
- 新建空白简历、恢复示例、JSON 完整备份与跨设备恢复
- 历史简历库：保存当前版本、恢复旧版本、删除记录，最多保留最近 30 份
- 可安装 PWA，支持桌面图标、独立窗口与离线启动
- 固定单页 A4 实时预览、内容比例自动适配、打印专用样式和 PDF 导出
- 桌面三栏工作台与移动端“模块 / 预览 / 编辑”三视图

## 技术栈

- React 19 + TypeScript
- Vite
- 原生 HTML5 Drag and Drop API
- CSS A4 排版与 `@media print`
- LocalStorage 本地持久化 + Service Worker 离线缓存

项目没有 UI 组件库和运行时 PDF 依赖，界面与图标均为项目内实现。PDF 通过浏览器打印引擎生成，文字保持为矢量内容，清晰度和可检索性优于截图式导出。

## 本地运行

```bash
npm install
npm run dev
```

浏览器访问 `http://127.0.0.1:5173`。

生产构建：

```bash
npm run build
npm run preview
```

## 导出 PDF

1. 在右上角点击“导出 PDF”。
2. 在系统打印窗口中选择“另存为 PDF”或“Microsoft Print to PDF”。
3. 纸张选择 A4、缩放选择默认值，并建议开启“背景图形”。

打印时编辑器、拖拽提示与选中边框会自动隐藏，只输出一张固定 A4 简历。内容增加时，应用会自动计算可用高度并缩放内部排版；工具栏会显示当前布局比例，内容极端过多时会提示精简。

## 数据与隐私

所有简历数据和历史版本仅保存在当前浏览器的 LocalStorage 中。新建、恢复示例或切换历史版本前，应用会自动保存当前版本。清理站点数据会同时清除已填写内容，建议定期从右上角“数据”菜单导出 JSON 备份；备份会包含历史简历，在任意设备均可恢复并继续编辑。

```text
    EditorPanel.tsx      # 动态内容表单与外观设置

    Icon.tsx             # 内置 SVG 图标
  App.tsx                # 状态、持久化与导出流程
  data.ts                # 模块元数据与示例简历
  templates.ts           # 18 套模板元数据
  types.ts               # TypeScript 数据模型
  styles.css             # 应用、模板、响应式与打印样式
public/
  manifest.webmanifest   # PWA 应用清单
  sw.js                  # 离线缓存
```
